# Final Project README

## How to Navigate This Repository

This repository contains the files for our final project.

To find the main project work, go to the `Final_project` folder.

Inside this folder, you will find the main explainer notebook:

`Explainer notebook_real.ipynb`

This notebook is the main notebook for the project. It contains the full explanation of our work, including the data, methods, analysis, visualisations, and discussion.

## Links Inside the Notebook

When you open the explainer notebook, you will find:

- A link to the GitHub repository
- A link to the project website

These links are included so the reader can easily access both the code repository and the final website.

## Project Website

The project website presents our final project in a more accessible and visual format.

On the website, we explain the main ideas, results, and findings from the project, following the final project requirements.

At the bottom of the website, the explainer notebook is also included, so the reader can view the notebook directly from the website.

## Summary

In short:

1. Open the `Final_project` folder.
2. Open `Explainer notebook_real.ipynb`.
3. Use the links inside the notebook to access the GitHub repository and the project website.
4. On the website, read about the final project.
5. Scroll to the bottom of the website to view the explainer notebook.
